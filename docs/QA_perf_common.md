# QA — Perf 티어 공통 데이터셋 (perf-1gb/10gb/100gb/200gb)

`perf-1gb`/`perf-10gb`/`perf-100gb`/`perf-200gb` 4개 Dataset(00_COMMON_SETUP.md 0.4
레지스트리 #6~9)에 **공통으로 재사용**할 50개 QA입니다. 아래 9개사는 4개 티어 중
`perf-1gb`(37개사 목록, 00_COMMON_SETUP.md 0.5절)에 이미 포함된 회사들이므로, `perf-1gb`
Dataset 하나에도 근거 문서가 전부 존재하고 `perf-10gb`/`perf-100gb`/`perf-200gb`는 그
상위집합이라 자동으로 포함됩니다 — 티어별로 별도 QA를 만들 필요 없이 이 50개를 각 티어에서
그대로 질의하면 됩니다(TC-DATA-06 "규모별 비교"의 취지에 맞게 동일 질문 → 규모별 응답 비교).

실제 DART 사업보고서·분기보고서·반기보고서 PDF 표지에서 직접 추출한 사실만 사용했으며,
추측·생성된 값은 없습니다. 03_DATA.md TC-DATA-06, 06_PERF.md TC-PERF-03/07에서 사용합니다.

## 사용 방법

- 회사명이 폴더명과 다른 경우가 있습니다: `006740_블루산업개발` 폴더의 실제 문서상
  회사명은 **영풍제지 주식회사**입니다(사명 변경 등으로 폴더명과 등기상 회사명이 다른
  것으로 보이며, 원본 데이터를 그대로 반영한 것입니다). 질문/정답은 문서에 실제로 적힌
  "영풍제지 주식회사"를 사용했으니, 소스 파일을 찾을 때는 `006740_블루산업개발` 폴더를
  보면 됩니다.
- 일부 질문에는 홈페이지 질문이 빠져 있습니다(1~30번은 6문항/사, 31~50번은 5문항/사) —
  50개를 맞추기 위한 것으로 품질 차이는 아닙니다.
